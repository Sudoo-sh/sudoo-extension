# بطاقة متجر Chrome الإلكتروني (العربية)

الصق كل جزء في الحقل المقابل له في لوحة مطوّري متجر Chrome الإلكتروني، بعد إضافة العربية لغةً ثانية للبطاقة.

## الاسم

Sudoo.sh

## الملخص (وصف قصير، 132 حرفًا على الأكثر)

لوحات Sudoo.sh في شريط الأدوات: المشاريع والبيئات وحالتها، وإجراءات سريعة، وبيئات الفروع في GitHub.

## الوصف

يشغّل Sudoo.sh بيئات Odoo لكل فرع Git على خادمك الخاص، كما يفعل Odoo.sh. وتضع هذه الإضافة لوحات Sudoo.sh على
بُعد نقرة واحدة وأنت تعمل.

في شريط الأدوات
- كل لوحة تربطها، مع مشاريعها (مستودع GitHub واحد لكل مشروع) وبيئاتها.
- الحالة بنظرة واحدة: تعمل، قيد العمل، متوقفة مؤقتًا، مطفأة؛ ومرحلة كل بيئة: الإنتاج أو التجهيز أو التطوير؛
  وفرعها وإصدار Odoo فيها.
- ابحث باسم البيئة أو الفرع أو المشروع أو المرحلة أو الإصدار.
- إجراءات سريعة: افتح Odoo، افتح في اللوحة، شغّل، أوقف مؤقتًا، أعد التشغيل، اجلب أحدث شيفرة. ويظهر تقدّم المهمة
  حتى تكتمل. وتطلب بيئات الإنتاج نقرة ثانية للتأكيد.

في الصفحة التي أنت فيها
- حين يكون التبويب إحدى بيئاتك، تعرضها النافذة أولًا مع «افتح في اللوحة» و«أعد التشغيل» و«سجل Odoo».
- في GitHub (اختياري): في صفحات مستودع هو مشروع على لوحاتك، يعرض زر Sudoo.sh صغير بيئة الفرع ومرحلتها وحالتها،
  ويقترح «أنشئ بيئة تطوير» لفرع ليست له بيئة. دون حاجة إلى رمز GitHub.

الإشعارات (اختيارية، معطّلة افتراضيًا)
- حين تكتمل مهمة أو تفشل، وحين ترفع لوحة تنبيهًا.

خاصة وبأقل الصلاحيات
- لا تتصل إلا باللوحات التي تربطها. لا تحليلات ولا تتبّع ولا شيفرة تُحمَّل من الإنترنت.
- كل طلب موقَّع (رمز وطابع زمني ورقم يُستخدم مرة واحدة وHMAC-SHA256)، كما تشترط واجهة API للوحة.
- تبقى الرموز في الذاكرة افتراضيًا وتُنسى حين يُغلق المتصفح؛ أو احفظها مشفّرة بعبارة مرور (AES-256-GCM).
- يُطلب الوصول إلى المواقع عنوانَ لوحة واحدًا في كل مرة؛ والوصول إلى GitHub والإشعارات حين تفعّلها فقط. ولا يعمل
  شيء داخل صفحات Odoo.

بالعربية والإنجليزية (من اليمين إلى اليسار)، بالمظهرين الفاتح والداكن. مفتوحة المصدر برخصة Apache 2.0:
https://github.com/Sudoo-sh/sudoo-extension

تحتاج إلى لوحة Sudoo.sh ورمز API تنشئه من صفحة رموز API فيها.

## الغرض الوحيد

تعرض مشاريع وبيئات لوحات Sudoo.sh الخاصة بالمستخدم، وتتيح له تنفيذ إجراءاتها الشائعة (الفتح والتشغيل والإيقاف
المؤقت وإعادة التشغيل والتحديث وإنشاء بيئة لفرع) من شريط الأدوات ومن صفحات GitHub للمستودعات التي تستخدمها تلك
اللوحات.
